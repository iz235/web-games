# Serious Game Prototype

A modern web-based serious game application designed for educational and interactive purposes.

## Architecture
This project is built using modern frontend tooling:
- **React**: For building the interactive user interface.
- **Vite**: For fast development and optimized building.
- **Tailwind CSS**: For utility-first styling and responsive design.

## Project Structure
- `/graphracer`: The main application folder containing the React components, assets, and styles.
- `GameCanvas.jsx`: The core interactive canvas component of the game.

## Running Locally

1. Navigate to the game directory:
   ```bash
   cd graphracer
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
