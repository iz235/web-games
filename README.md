# Web Games & Interactive Applications

This repository contains interactive web-based games and applications developed with modern web technologies (React, Vite, TailwindCSS, etc.).

## Projects Included

### 1. [GraphRacer Game](./jeu_garph/README.md)
A web-based game involving graph traversal and racing mechanics. Built with Node.js and features a detailed LaTeX presentation of its architecture.

### 2. [Serious Game](./Serious_Game/README.md)
An educational/serious game prototype built with React and Vite, utilizing Tailwind CSS for styling and interactive UI components.
